# 师生账号与班级管理

仅用于 [云端测试入口](https://miraitowa73.github.io/dcdv-next/cloud-test/)。主站仍使用原来的本地账号；编译、原理图、状态图及仿真服务不变。

## 使用方式

- 管理员 `miraitowa` 在“老师管理”创建老师或给已有账号授予老师权限；撤销权限立即生效。新老师的随机临时密码只在创建结果中显示，首次登录必须修改。管理员可以重新签发临时密码，旧会话同时失效。
- “登录账号”与“显示姓名”分别保存。管理员可以在老师列表点击“修改姓名”；老师可在教学空间顶部点击“修改姓名”，填写中文姓名。修改仅更新显示姓名，不改变登录账号、密码、权限、班级或进度；学生所属班级中的负责老师名称会同步更新。首次改密前不允许修改姓名，学生不能调用老师姓名修改接口。
- 老师登录进入“我的班级”，创建班级后下载 Excel/CSV 模板，填写文本格式的“学号、姓名”。每次最多 500 人，先预览，再确认导入。前导零保留；重复和错误行不执行；姓名冲突必须单独确认。每批 5 人依次执行，失败行可以重试。
- 新导入学生用学号和学号后六位登录，首次必须修改为 8–72 位密码。已有学生保留密码、个人资料和学习进度，只增加班级关系。老师和管理员不能作为学生导入。
- 公众注册只能创建学生，学号为 6–24 位数字或英文字母。旧非学号账号仍可登录，本期不自动改名或合并。
- 每个班级一位负责老师。学生可在多个班级，共用同一份 39 关进度；学生“我的班级”说明老师可查看的范围。
- 老师可搜索学号/姓名、按完成率排序，每页 50 人，手动刷新；班级名单增加通关总耗时、错误次数，明细返回关卡完成状态、最新判定、提示次数及逐关耗时、错误次数。移出班级后通过该班的查看权限立即失效；归档和移出都不会删除账号或进度。

## 耗时与错误次数

- 耗时累计当前关卡页面在前台的时间，首次通过时冻结；切换关卡、离开闯关页面或浏览器进入后台时暂停。按 15 秒心跳累计，持续学习时约每分钟沿用现有进度接口同步；提交和页面切换时同时保存。浏览器异常关闭仍可能丢失尚未同步的短时记录。
- 错误次数统计首次通过前提交判定失败的次数，包括答案、语法、端口及行为不符；网络或服务故障不计，独立编译检查不计。重复点击同一次正在执行的提交只处理一次；通过后的复习不改写首次记录。
- 已完成关卡的耗时相加为通关总耗时；错误总次数包括尚未完成的关卡。跨设备继续时使用云端已保存的累计值，沿用进度版本冲突保护。
- 旧进度没有统计时显示“未记录”；更新前已开始但未完成的关卡，从更新后继续记录并显示“≥”，表示只知道下限。混合新旧通关记录时展示已有记录的关卡数，不虚构历史耗时或零次错误。
- 统计仍由学习端提交，用于教学跟踪；老师只能看到所属班级学生的精简统计，不获得答案或代码。

## 存储与权限

复用 `dcdv-next-account` 和 `dcdv-accounts`；新增 `dcdv_classes`、`dcdv_class_members`，STRING 主键 `key`、TTL -1、maxVersions 1、预留读写 CU 为 0。不创建常驻服务器、搜索索引或计费套餐。

`classes` 保存权威班级记录 `c:<id>`，老师班级索引 `owner:<teacherId>:<id>`，老师索引 `teacher:<username>`，以及不含密码的操作审计。`class_members` 保存权威成员关系 `c:<classId>:<userId>` 和学生索引 `s:<userId>:<classId>`。所有查询通过已授权前缀分页，不扫描全表；索引先写、权威记录后写，读索引必须重新检查权威记录。索引失败可重试，孤立索引不授予权限。

`progress` 在同一次条件写入中保存个人原始进度和精简统计列。老师接口仅投影读取统计列，旧数据没有统计时在后端兼容计算。教师明细不返回答案、HDL、原理图、状态图、错误日志或原始草稿。教学进度由学习端提交，不作为防作弊考试成绩。

后端每次请求读取当前身份和会话版本；客户端伪造身份无效。首次改密前只允许 `me`、`logout`、`change-password`。首次设置使用已验证临时密码的受限登录会话，无需重复输入临时密码；只有数据库中的首次改密标记允许此流程。普通改密仍必须校验当前密码。改密使其他会话失效；撤销老师身份后旧会话立即失去老师权限。旧用户缺少 role 时视为学生。

RAM 策略见 `ram-policy.template.json`：5 张表仅 GetRow/PutRow，新增两表允许 GetRange，DeleteRow 仅 ephemeral。导入预览和逐行完成标记存放于已有 ephemeral 表；有期限、绑定操作者和班级；不在浏览器保存密码。

## 管理员一次性初始化

1. 通过有 RAM 权限的阿里云控制台暂时设置函数环境变量 `DCDV_BOOTSTRAP_ADMIN=1`，保留现有四个配置变量。
2. 使用 RAM 鉴权的直接 InvokeFunction 事件 `{"operation":"bootstrapAdmin"}`，不是 HTTP 触发器。返回随机临时密码，仅在此次响应显示；不写入代码、配置、日志或部署记录。
3. 立即删除初始化开关并部署。账号名已存在时初始化停止，不覆盖密码、不自动提权。
4. 管理员首次登录测试入口后自行设置新密码，才可管理老师。
